Configuration

One-to-all computes a distance field for repeated queries. One-to-one computes a path to a specified goal configuration. The approximate mode uses A* ordering and may return longer paths or miss a path.

Set start or goal: click to place, drag its arrow to orient. Query path: drag across goal positions. 0° points right, 90° down.
